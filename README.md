# Прощай и здравствуй

Это автономная статическая сборка сайта. Для публикации загрузите **содержимое** этой папки на любой static hosting.

Внутри нет исходных PDF, TIFF, OCR, review-файлов, node_modules или браузерных профилей. Все пути относительны, поэтому сайт можно размещать и в подпапке домена.

Из корня исходного проекта:

```powershell
npm.cmd run build:replace   # пересобрать dist после правок
npm.cmd run verify:deploy  # проверить автономность релиза
npm.cmd run preview        # локально открыть dist
```
